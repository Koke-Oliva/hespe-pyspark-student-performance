# Dataset — Higher Education Students Performance Evaluation (HESPE)

El archivo `hespe-data.csv` corresponde al dataset **Higher Education Students Performance Evaluation**.

- Fuente: UCI Machine Learning Repository
- DOI: https://doi.org/10.24432/C51G82
- Dataset: https://archive.ics.uci.edu/dataset/856/higher+education+students+performance+evaluation
- Autores: Nevriye Yilmaz y Boran Şekeroğlu
- Licencia: **CC BY 4.0**

La licencia permite compartir y adaptar el dataset siempre que se otorgue atribución adecuada.

## Características

- 145 observaciones
- 31 features
- 1 identificador de estudiante
- target `grade` con 8 categorías: `Fail`, `DD`, `DC`, `CC`, `CB`, `BB`, `BA`, `AA`
- sin valores faltantes en la versión utilizada

## Archivo de este repositorio

El CSV fue normalizado a nombres de columnas descriptivos en `snake_case` y usa `;` como separador.
